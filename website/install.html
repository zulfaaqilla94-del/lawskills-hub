Get Started

Pick where you use AI. Every option gives you the same skills.

Claude Desktop

A one-click Desktop Extension. It runs a small local server that loads skills from this site, so new skills arrive without reinstalling.

  1. Download the extension file below.
  2. Double-click the .mcpb file, and Claude Desktop opens it.
  3. Choose Install, then start a new chat and describe your task.
Download Extension (.mcpb)

A Custom GPT that loads skills on demand. There is nothing to download or update. Using it requires a ChatGPT plan with access to GPTs.

Claude Code & other agents

Any agent that supports Agent Skills can use these files. A .skill file is a zip archive containing a folder with a SKILL.md.

  1. Download the meta skill for your role from the catalog. It bundles all of that role’s skills.
  2. Unzip it into your agent’s skills folder. For Claude Code: 
    mkdir -p ~/.claude/skills
unzip ~/Downloads/student-meta.skill -d ~/.claude/skills
  3. Start a new session and describe your task. For other agents, check their documentation for the skills folder location.

Developers

Build the whole site locally. You need uv and git.

  1. Get the source: 
    git clone {{ repo_url }}
cd lawskills-hub
  2. Build it: 
    uvx --from "git+https://github.com/harvard-lil/skills-hub#subdirectory=packages/skills-hub-builder" skills-hub-builder build
  3. Preview it at http://localhost:8000: 
    python3 -m http.server -d _site
